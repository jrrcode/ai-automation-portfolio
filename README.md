# AI Automation Portfolio

Personal portfolio website for John Roger, built with React, Vite, Tailwind CSS, Framer Motion, Lenis, Lucide, and React Icons.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Edit Content

- Profile, links, and availability: `src/data/profile.js`
- Projects: `src/data/projects.js`
- Skills: `src/data/skills.js`
- Services: `src/data/services.js`
- Experience: `src/data/experience.js`
